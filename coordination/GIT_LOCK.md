# مشکل قفل گیت

## وضعیت

فایل `.git/index.lock` از **۲۰۲۶-۱۰-۰۱ ساعت ۱۷:۰۱** باقی مانده.
تا این لحظه هنوز پاک نشده و **هیچ‌کدام از ما دو ایجنت نمی‌توانیم کامیت کنیم.**

## چرا مهم است

تا وقتی این قفل هست:
- `git add` و `git commit` هر دو با خطا شکست می‌خورند
- اگر کارمان نیمه‌کاره بماند، **راهی برای برگرداندنش نیست**
- اگر دو ایجنت همزمان روی فایل‌های مشترک بنویسند، کار یکی‌تان برای همیشه می‌رود

## راه‌حل

**روی ویندوز، قبل از ادامه‌ی کار:**

```powershell
cd g:\v\IDE

# 1. برنامه‌ها را ببندید (VS Code، Antigravity، Claude Desktop)
#    یک بار ببندید و دوباره باز کنید

# 2. قفل یتیم را پاک کنید
Remove-Item .git\index.lock -Force

# 3. کامیت پایه
git add backend/ frontend/src/ coordination/ AGENTS.md
git commit -m "wip: checkpoint before dual-agent work"
```

## اگر باز هم قفل بود

یعنی فرایند گیتی جایی در حال اجراست. پیدا کنیدش:

```powershell
Get-Process git* -ErrorAction SilentlyContinue
```

و آن را ببندید، بعد دوباره تلاش کنید.

## ⚠️ هشدار

**هرگز `index.lock` را با `rm -f` در لینوکس پاک نکنید مگر مطمئن باشید**
هیچ فرایند گیتی فعال نیست. پاک کردن قفل یک فرایند در حال کار می‌تواند
ایندکس گیت را خراب کند و کل تاریخچه‌ی پروژه از بین برود.

## 💡 راه‌حل بلندمدت

تا وقتی کامیت ممکن نشود، هر تغییری فقط در حافظه‌ی همین نشست‌ها وجود دارد.
**هر کار را که تمام کردید فوراً بگویید تا در لاگ بنویسم** — اگر مشکلی پیش
آمد، دست‌کم از فایل‌های لاگ می‌شود بازسازی کرد.
