## 🐛 مشکلاتی که در کار Antigravity پیدا کردم

### ۱. fallback به `flash_5` غلط است — `agent.go:262-272`

وقتی مدل اصلی شکست می‌خورد، این کد دوباره با مدل `flash_5` درخواست می‌فرستد

**راه‌حل:** برای هر مدل باید کلید و آدرس خودش از `ResolveProvider` گرفته شود:

if route, ok := ResolveProvider("flash_5"); ok {
    apiKey = sCtx.APIKeys[route.apiKeyName]

یا بهتر: **کلاً fallback را حذف کنید.** اگر مدل اصلی جواب نداد، خطا بدهید.
اینکه بحث ۵ ایجنت با یک مدل متفاوت و کلید اشتباه جواب بگیرد، بدتر از خطا دادن است.
